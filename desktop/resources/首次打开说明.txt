源页（PageRoot）· 公开预览版
Edit visually. Stay in source.

适用设备
Apple 芯片 Mac（arm64）。

安装
1. 把“PageRoot”拖到右侧“Applications”。
2. 打开“应用程序”，按住 Control 点击“PageRoot”，选择“打开”。
3. 在系统提示中再次选择“打开”。这只在首次运行时需要。

开始使用
1. 第一次启动且没有可恢复项目时，源页会建立“欢迎来到源页.html”及其独立项目记录，你可以直接用它体验编辑、评论和 AI Agent 交接。也可以点击左上角当前项目，打开已有的本地 HTML，或切换最近项目；仅打开和预览其他 HTML 不会修改源文件。
2. 单击页面内容进行选择；双击 source-backed 静态文字后，光标会直接落在点击位置，普通文字和安全的混合行内文字都可原位编辑。定位或布局安全性无法证明时，工作台会说明原因并阻止写入，不会猜测目标。
3. 文字约 700ms 后形成源码 checkpoint；文字、当前元素 inline 样式、安全结构变化和同级顺序都通过源码局部 Patch 自动更新到当前源 HTML。顶部显示真实状态和最后更新时间，不需要点击保存。
4. 点击浮动工具条里的“评论”，右侧才会出现输入框；可直接粘贴图片或用“添加图片或文件”选择本机文件。图片可点击放大、悬停移除；发送或取消后输入框会收起。
5. 画布不增加新的撤销按钮；直接使用系统 Edit 菜单、Cmd+Z 撤销和 Shift+Cmd+Z 重做。文字、样式、安全结构与上移/下移的源码历史会随项目保存，重开后仍可继续。焦点在评论、项目规则或其他文字输入框时，只撤销当前输入框文字；评论卡片、附件和其他项目操作不会被撤销。
6. 点击“发给 AI”后，先选择“用 Qoder CLI 自动执行”或“只复制任务”。自动模式先检查独立安装的 Qoder CLI 来源、版本、文件身份和静态模型列表；这只证明本机 CLI 已准备好，真正会话仍可能遇到登录、容量或网络失败。检查期间只防重复发送，画布仍可编辑；失败不会锁定、不会建立 Request。Qoder 使用你的本机账号和系统权限，ACP 限制不是操作系统沙箱；选择自动执行表示你信任这份本机 Qoder CLI。
7. readiness probe 或复制准备通过后，工作台完成项目登记，再冻结届时最新的文字、评论和规则；冻结、自动写回 revision 与磁盘 Hash 全部核对成功后才锁定当前项目。自动模式由源页启动、显示进度并可停止 Qoder，不接触剪贴板；复制模式只有在系统剪贴板写入并逐字回读成功后才显示“已复制”，再由你粘贴给任意本地 Agent。Bridge 崩溃或留下未最终化输出时，旧 Request 不允许重新启动或改为复制；结束本轮形成安全 fence 后再重新发送。附件始终保存为当前 Request 的项目内快照，不依赖桌面或下载目录中的原文件。
8. AI 结果通过检查后会先作为独立候选保留，不会自动替换当前 HTML。“审阅对比”是首要操作：源页并排显示修改前与 AI 修改后，文案、结构和视觉变化分别标出，原评论仍显示在修改前的对应位置。
9. 审阅时可以切换双页、左页或右页，筛选变化类型，调整未修改区域的可见度，并选择同步或独立滚动。看完后可“打开 AI 修改后”，也可“返回 AI 修改前”继续编辑；AI 候选仍会保留。
10. 复制模式下，如果用户在 QoderWork 或其他 Agent 对话中增加 Prompt、图片或文件，Agent 必须先按 Prompt 运行受控记录命令；记录成功后才执行，并在该版本历史中归入“内部 AI 对话补充”。受管 Qoder ACP 只执行发送时冻结的本轮要求；需要改变要求时先停止本轮，再建立新 Request。
11. “导出 HTML 副本”只复制当前内容，不改变当前项目，也不会增加版本号。

版本说明
本地编辑、自动写回和导出都不创建版本。版本只记录初始基线和内部 AI 通过硬校验后的有效返回。历史查看始终只读，不提供替换当前 HTML 的入口。

使用数据说明
正式桌面版本默认把有限、结构化的使用与故障统计通过 HTTPS 回传到源页的 PostHog US Cloud 项目，用于了解功能使用、错误、提醒和流程中断。源页使用首次运行随机生成的安装 ID，不读取电脑序列号、Apple 账号或设备名；项目只使用本机密钥生成的假名标识。
PageRoot 产品遥测不会回传 HTML 源码、页面文字、文件名或路径、评论/Prompt/AI 返回内容、附件、剪贴板、原始错误消息或堆栈。用户主动选择 Qoder 自动执行后，本轮资料、Request 内本机路径及 Qoder 账号/会话所需元数据可能按 Qoder 的条款由其服务处理；这不属于 PageRoot 遥测。连续编辑与成功保存会先在本机汇总；不启用自动捕获或会话录像。完整边界见应用包内 PRIVACY.md 与“关于源页”。

检查更新
源页启动后会由桌面后端自动检查更新，正常情况下前端不显示任何额外内容。发现新版本后，左上角 Logo 右下角会出现“new!”；点击 Logo 会打开源页 GitHub 项目页。下载新版 DMG 后，将英文安装包“PageRoot”拖入“Applications”并确认替换。当前版本不会在后台静默下载安装。

项目记录
Prompt、Request、AI 产出、事务、版本和审计记录默认保存在：
~/Documents/PageRoot/项目记录/projects

工作区固定为 ~/Documents/PageRoot/项目记录。旧目录不会被读取或删除。没有可恢复项目的首次启动会把“欢迎来到源页.html”作为普通 HTML 建立独立项目记录和初始 V1，且以后不会用内置模板覆盖用户修改。其他新打开 HTML 仍只在第一次真实编辑、添加评论附件或发送给内部 AI 时登记项目。
应用内“项目文件”会显示当前 HTML 与实际项目记录的完整位置，并可直接在 Finder 中打开。

如果仍被系统阻止
打开“系统设置 → 隐私与安全”，在页面下方找到 PageRoot，点击“仍要打开”。
