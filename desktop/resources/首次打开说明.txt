源页（PageRoot）0.8.7 · 公开预览版
Edit visually. Stay in source.

适用设备
Apple 芯片 Mac（arm64）。

安装
1. 把“PageRoot”拖到右侧“Applications”。
2. 打开“应用程序”，按住 Control 点击“PageRoot”，选择“打开”。
3. 在系统提示中再次选择“打开”。这只在首次运行时需要。

开始使用
1. 第一次启动且没有可恢复项目时，源页会建立“欢迎来到源页.html”及其独立项目记录，你可以直接用它体验编辑、评论和 QoderWork 交接。也可以点击左上角当前项目，打开已有的本地 HTML，或切换最近项目；仅打开和预览其他 HTML 不会修改源文件。
2. 单击页面内容进行选择；双击 source-backed 静态文字后，光标会直接落在点击位置，普通文字和安全的混合行内文字都可原位编辑。定位或布局安全性无法证明时，工作台会说明原因并阻止写入，不会猜测目标。
3. 文字约 700ms 后形成源码 checkpoint；文字、当前元素 inline 样式和同级顺序都通过源码局部 Patch 自动更新到当前源 HTML。顶部显示真实状态和最后更新时间，不需要点击保存。
4. 点击浮动工具条里的“评论”，右侧才会出现输入框；可直接粘贴图片或用“添加图片或文件”选择本机文件。图片可点击放大、悬停移除；发送或取消后输入框会收起。
5. 选中元素浮动工具条里的“撤销”只撤销文字、样式和排序等直接编辑；评论请在右侧单独删除。
6. 点击“一键发送至 QoderWork”后，工作台会先提交仍在编辑的文字，并核对自动写回 revision 与磁盘 Hash；全部成功后才锁定当前项目。失败时不会锁定、不会建立 Request，也不会复制旧内容。
7. 只有系统剪贴板写入并逐字回读成功后，界面才显示“已复制”。源页不会自动打开、控制或粘贴到 QoderWork；请在 QoderWork 新建对话后自行粘贴。附件已保存为当前 Request 的项目内快照，交接只提供这些快照的本机路径，不依赖桌面或下载目录中的原文件。
8. 右侧“本轮流程”会显示返回、身份/Hash/完整性、范围与质量、建版等步骤。安全与协议校验不可忽略；若 AI 还修改了评论范围外的内容，源页会展示变化摘要，由你选择是否“采用这些额外变化”，并留下审计记录。
9. 新版本通过后先安全保留，左侧继续显示旧版。只有用户点击“打开 Qoder 返回的最新版”后，才切换到最新工作文件。
10. 如果用户在 QoderWork 对话中增加 Prompt、图片或文件，内部 AI 必须先按 Prompt 运行受控记录命令；记录成功后才执行，并在该版本历史中归入“内部 AI 对话补充”。
11. “导出 HTML 副本”只复制当前内容，不改变当前项目，也不会增加版本号。

版本说明
本地编辑、自动写回、导出和历史恢复都不创建版本。版本只记录初始基线和内部 AI 通过强制范围校验后的有效返回。历史查看为只读，替换当前 HTML 也不会创建新版本。

检查更新
源页启动后会由桌面后端自动检查更新，正常情况下前端不显示任何额外内容。发现新版本后，左上角 Logo 右下角会出现“new!”；点击 Logo 会打开源页 GitHub 项目页。下载新版 DMG 后，将英文安装包“PageRoot”拖入“Applications”并确认替换。当前版本不会在后台静默下载安装。

项目记录
Prompt、Request、AI 产出、事务、版本和审计记录默认保存在：
~/Documents/PageRoot/项目记录/projects

工作区按“PageRoot/项目记录 → YuanYe/项目记录 → HTML AI 工作台/项目记录”的顺序选择；已存在 PageRoot 时优先使用，否则沿用已有旧目录。没有可恢复项目的首次启动会把“欢迎来到源页.html”作为普通 HTML 建立独立项目记录和初始 V1，且以后不会用内置模板覆盖用户修改。其他新打开 HTML 仍只在第一次真实编辑、添加评论附件或发送给内部 AI 时登记项目。
应用内“项目文件”会显示当前 HTML 与实际项目记录的完整位置，并可直接在 Finder 中打开。

如果仍被系统阻止
打开“系统设置 → 隐私与安全”，在页面下方找到 PageRoot，点击“仍要打开”。
