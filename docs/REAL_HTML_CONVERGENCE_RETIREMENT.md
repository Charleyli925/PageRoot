# Real HTML convergence and retirement ledger

This ledger records the M4 decision. The public Electron command was retired
as an automatic-discovery qualification entry and replaced by a reviewed
composite-plan dispatcher. Existing low-level executors and specialized lanes
remain available because their independent boundaries are not proven redundant.

## Deletion and rollback proof

No low-level executor, specialized lane, result oracle or product behavior was
deleted. The rollback point for the public entry is the M3 commit: reverting it
restores the old package command, while M2's pure contracts and M1 evidence can
remain independently. If the new dispatcher must be disabled, restore the old
command only together with the old documentation and gate mapping; do not leave
the package script, inventory and risk ownership in a mixed state.

## Coverage that is deliberately not retired

The private corpus, 20/50/100 cycle activities, IME candidate-window boundary,
arbitrary rich clipboard preservation, source transaction and permission
contracts, and the separate runtime-generated capability matrix still require
their own materials and evidence. A passing composite plan is not a claim that
those activities ran. Missing or empty private material is reported as
`NOT_EXECUTED`/blocked, never as synthetic acceptance.
